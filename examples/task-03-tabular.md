## 题目：<工艺条件> 到 <目标产率> 的预测

### 题目背景与目标

给定 <N> 条实验记录（特征 <D> 维，含 <类型> 混合特征），预测 <目标值>。
该任务考察对**特征工程、数据泄漏识别、模型选择与验证策略**的理解，而非模型规模。

### 数据加载

```python
import pandas as pd
train = pd.read_csv(<训练集路径>)
test  = pd.read_csv(<测试集路径>)
```

- 训练集含 `<目标列>`，测试集不含。
- 存在缺失值、类别型字段、量纲差异，**需自行处理并在 README 说明**。
- 存在 <k> 条重复/矛盾记录，需自行判断。

### 要求

1. 必须使用**交叉验证**选择模型，禁止在测试集上调参。
2. 必须报告**至少两种**模型的对比结果。
3. 特征工程需说明每一步的动机（不能只写"试了一下"）。
4. 必须检查并说明是否存在**数据泄漏**（例如 <某列> 与目标的关系）。
5. 固定 seed，保证结果可复现。

### 提交内容

| 文件 | 内容 |
|---|---|
| `test_result.json` | `{"predictions": [...]}`，条数与顺序对齐测试集 |
| `README.md` | 六段式，含特征表与模型对比表 |
| `代码` | `--mode smoke` 能跑 |
| `train.log` | CV 每折指标 + 最终模型指标 |

### 评分

主指标 <RMSE 或 AUC>。加分项：泄漏分析写得好、消融表完整。

## 这一题型该走哪条线

| 步骤 | 做法 |
|---|---|
| 情报 | 先看分布与缺失率；这一步比选模型重要 |
| 方案 | SAFE = LightGBM 默认参数（5 分钟出分）；SOTA = 特征工程 + 调参；GREEDY = 多模型融合 |
| 执行 | 先跑 5 折 CV 拿基线，再动特征 |
| 提分顺序 | 验证策略修正 → 缺失值标记位 → 类别编码 → 目标编码 → 融合 |

## 这类题的五个坑

1. **一上来上深度学习**：样本几千条时树模型几乎总赢。
2. **在测试集上调参**：这是最常见的违规，也会让你线上崩。
3. **没查泄漏**：某个特征其实是目标的代理，CV 分数虚高，测试集直接腰斩。
4. **交叉验证没按组划分**：同一批次样本同时出现在 train/valid，指标虚高。
5. **只报一个模型**：题目要对比，只给一个数字丢分。
