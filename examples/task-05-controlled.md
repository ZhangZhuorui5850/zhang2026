# 题型五 · 受控比较 / 消融（虚构示例，仅示意题面风格）

> ⚠️ 全部虚构。真实题目不同。`<>` 为占位符。
> 这一类的特征是：**题目不追求高分，追求"你能不能证明某个改动真的有用"**。

---

## 题目：<某改动> 是否改善 <某任务> 的受控验证

### 题目背景与目标

给定固定数据、固定划分与固定预算，比较 <基线结构 A> 与 <候选结构 B>，
并按**事先写定的选型规则**选出提交版本。要求给出可复现程序、全部结果与一页结论。

> 关键：**没有提升也能通过**。评的是过程是否受控、结论是否被证据支持，而不是分数。

### 数据加载

```python
from <module> import load
Xtr, ytr, Xva, yva, Xte, yte = load(<数据路径>)   # 划分已固定，禁止重划
```

- 存在 <k> 条重复记录，需说明你如何处理（保留 / 去重 / 聚合），并说明对划分的影响。
- 特征含 <类型> 混合，**缩放只能使用训练集统计量**。

### 要求

1. **冻结配置**：训练步数、优化器、学习率、batch 提前写死，两个模型共用，不许各自调参。
2. **三个种子全跑**，报告每个种子的结果，不许只报最好的。
3. **选型规则提前写定**（如"验证集均值高者胜，平局取参数少者"），并在代码里实现为函数。
4. **测试集只用一次**，且必须在选型冻结之后。
5. 每个候选必须写**反驳条件**：什么结果会证明这个改动无效。

### 提交内容

| 文件 | 内容 |
|---|---|
| `test_result.json` | 冻结版本的测试输出 + `selected` 字段说明选了哪个 |
| `README.md` | 含受控条件表、三种子全表、选型规则原文、反驳条件 |
| `代码` | 能复现全部六次训练（2 结构 × 3 种子） |
| `train.log` | 六次运行的完整轨迹 |

### 评分（六维，参考 ZGCA 实训量规）

数据与协议 20 / 基线与指标 20 / 有理由的候选 20 / 受控比较 15 / 可复现交付 15 / 一页结论 10。
**红线**：测试集调参、重复样本跨划分、虚构结果 → 不通过。

---

## 这一题型该走哪条线

| 步骤 | 做法 |
|---|---|
| 情报 | 先确认"受控条件"到底控了哪些（步数/优化器/初始化方式），这是本节唯一考点 |
| 方案 | SAFE = 只跑基线 + 一个候选，三种子；SOTA = 再加一个候选；GREEDY = 无用，别做 |
| 执行 | 把"选型规则"写成代码里的函数，先写函数再跑实验 |
| 提分 | 这类题不靠提分。把精力放在**反驳条件**和**配对差**上，这是 15 分的受控比较维度 |

## 这类题的五个坑

1. **两个模型各自调参**：受控比较直接作废，20 分归零。
2. **只报最好的种子**：量规明确要求"六次全部结果"。
3. **选型规则事后编**：必须在看测试集之前冻结，最好写进代码注释 + 时间戳。
4. **平局不算**：验证均值相同必须按预先规则裁决（如参数少者胜），不能"随便选一个"。
5. **结论超出证据**：验证集没赢就不能写"提升了泛化"；只能写"本次验证未观察到提升"。
