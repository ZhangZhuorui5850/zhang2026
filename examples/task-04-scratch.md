## 题目：<小规模时序> 异常检测

### 题目背景与目标

给定 <传感器/日志> 时序数据（正常样本为主，异常标注稀少），要求**从零实现**一个异常检测模型
（不提供预训练权重），并在测试集上按 <指标> 评测。
本题考察：无监督/半监督建模思路、指标选择、以及**对不平衡数据的处理**。

### 数据加载

```python
from <module> import load_series
train = load_series(<训练集路径>, split="train")   # 只有正常样本
test  = load_series(<测试集路径>,  split="test")    # 含异常与标签
```

- 序列长度不一，需自行 pad / 切窗。
- 异常比例约 <p>%，**极度不平衡**。

### 要求

1. **不许使用任何预训练权重**，模型结构自行设计（参数量 < <上限>）。
2. 必须说明**为什么该指标适合不平衡数据**（Accuracy 在这里没有意义）。
3. 必须给**阈值选择策略**（如按验证集 F1 最大化），而不是默认 0.5。
4. 必须给**至少一组消融**（去掉某个模块后指标变化）。
5. 训练必须能在 <T> 分钟内完成一轮，否则方案不可行。

### 提交内容

| 文件 | 内容 |
|---|---|
| `test_result.json` | `{"scores": [...], "threshold": <float>}`，长度 = 测试集窗口数 |
| `README.md` | 六段式，含结构图说明与消融表 |
| `代码` | `--mode smoke` 能跑 |
| `train.log` | 每 epoch 的 loss 与该 epoch 的验证指标 |

### 评分

主指标 <F1 / AUPRC>。加分项：消融完整、阈值策略有依据、说明了为什么不用 Accuracy。

---

## 这一题型该走哪条线

| 步骤 | 做法 |
|---|---|
| 情报 | 先搞清楚指标定义（窗口级还是点级）、异常在测试集里怎么标 |
| 方案 | SAFE = 统计基线（如 3σ / IQR / PCA 重构误差）；SOTA = 自编码器/VAE；GREEDY = 多方法打分融合 |
| 执行 | **先跑通统计基线**，它往往已经是及格线以上，再上模型 |
| 提分顺序 | 指标口径确认 → 阈值策略 → 窗口长度 → 模型结构 → 融合 |

## 这类题的五个坑

1. **默认阈值 0.5**：不平衡数据下几乎必错，一定要搜阈值。
2. **报 Accuracy**：99% 正常样本，全判正常也有 99%，直接暴露理解问题。
3. **窗口泄漏**：切窗时 train/test 有重叠帧，指标虚高。
4. **模型太大**：题目给了参数量或时间上限，超了等于没做。
5. **没有消融**：复现类题目的主要得分点就是消融表。
